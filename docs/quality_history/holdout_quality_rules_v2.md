# MELFA holdout quality rules, v2 — source-row index and 31-row descriptors

This amendment is recorded before any of the four candidate measurement payloads is opened. It preserves all four members of `holdout_membership_freeze.json` and the complete v1 document `holdout_quality_rules.md`. It replaces v1's generic time/window wording with the actual method developed only on historical training/validation records. The superseding relationship and hashes are recorded in `quality_amendment_v2.json` and `quality_v2_freeze.json`.

**Method scope.** The frozen input descriptors use local standardized velocity and acceleration energies over 31 original supplied rows, plus their log/ratio transformations. Standardization and epsilon are learned/fixed using the historical training pool, not these holdout records. Features are dimensionless; no MELFA frequency in Hz, seconds-based spectrum, measured timestamp or physical sampling period is claimed. An absent `t` column does not fail this audit.

1. **Opening authority stays pending.** The root must first freeze the complete method, coefficients, parameters, normalization, member set, 31-row descriptor implementation, endpoints, comparisons, aggregations and stopping rules. The root's final freeze must bind the original member digest and the v2 quality digest. This amendment does not open data or authorize a prediction. A subsequent explicit root notice starts the single coordinated quality reveal.
2. **Member identity.** Before parsing, verify the unchanged source archive SHA-256 and each frozen member path, uncompressed size and ZIP CRC. At reveal, record each decompressed member SHA-256. Preserve all four records, including `MELFA_range1.4_seed5`; metadata file size and filename duration are not exclusion criteria.
3. **Required numerical schema.** Require the six joints' `q_filt_1..6`, `dq_filt_1..6`, `ddq_filt_1..6` and `tau_filt_1..6` columns. All required columns must be numeric, finite, row-aligned and the same length as the source DataFrame index. A mechanical pass/fail check on force/torque values is allowed during quality reveal; no target values, distributions, residuals or method metrics enter the quality report or eligibility decision. Preserve failures rather than silently cleaning individual rows.
4. **Source index, not a fabricated clock.** Require a finite numeric source DataFrame index, in the supplied acquisition order, with strictly positive consecutive differences. An initial value of zero is valid. An increasing jump such as 0 to 700 is a gap, not an error and not an elapsed-time measurement. Keep the original index; do not reset it to `0..n-1`, sort rows, deduplicate rows, infer timestamps or assign Hz. If code converts the index to an integer array, confirm that the representation is lossless rather than silently rounding it. Unsupported or ambiguous index encoding is a logged quality issue.
5. **Split at every index discontinuity.** Put a segment boundary before every row for which `index[i] - index[i-1] != 1`. Smooth only within each segment. A source gap is retained in the metadata; adjacent segments are never stitched or filled with manufactured measurements.
6. **Window feasibility and edge retention.** Each record must contain at least one segment with **31 consecutive source-index rows**. Use the frozen centered 31-row mean (15 rows on either side) with `mode='nearest'` endpoint extension within each segment. The source implementation applies this extension to every segment, including shorter segments; do not discard edge rows or those shorter segments if the record passes the at-least-one-31-row-segment rule. Padding duplicates the nearest endpoint for descriptor calculation only and does not create new measured samples. Do not cross a gap. Any later every-tenth-row evaluation sampling follows the separate frozen evaluation plan and does not alter the raw-row feasibility check.
7. **Do not force clock recovery.** A timestamp column is optional metadata. The absence of `t`, lack of a source sampling period, or inability to convert the source index into seconds does not exclude a record from this index-based descriptor analysis. No seconds/Hz interpretation may be added afterward. If timestamps are present, record their provenance without replacing the index-defined segment rule.
8. **Release all quality results together.** Before prediction, produce one complete ledger for the four members: identity, required-column coverage, finite checks, original index encoding, monotonicity, gap count, segment lengths, whether a length-31 segment exists, row count, and pass/fail/unknown. Keep every quality failure in the original inventory. A short but valid record is included and individually reported. No model output, score, error, favorable regime or method ranking is available to this decision.
9. **Holdout and inference boundaries.** Do not update normalization, signal scales, window length, coefficients, selection rules, weights or endpoints using holdout inputs or targets. Apply any separately frozen input-identity audit uniformly and before prediction; do not exclude geometrically difficult records. Preserve shared-seed relationships: range 0.5 seed 6 relates to already seen range 1.4 seed 6; range 1.4 seeds 0 and 10 relate to already seen range 0.5 seeds 0 and 10. These are same-source new records, not new independent hardware or motion-acquisition sessions.
10. **After quality freeze.** The root follows the predeclared evaluation protocol on every quality-passing record. Report each retained record and the frozen aggregate. Performance cannot trigger record removal, retuning, altered edge handling, reweighting or a new method variant.

The amendment is justified by the exposed-development implementation `work/signal_extension/code/prepare_development.py`: `features` splits on nonconsecutive source indices and calls `uniform_filter1d(..., size=31, mode='nearest')` separately on each segment. The MELFA feature configuration labels the quantities dimensionless and assigns no Hz. This evidence concerns historical training/validation data and code; it is not an inspection of the four candidate payloads.
